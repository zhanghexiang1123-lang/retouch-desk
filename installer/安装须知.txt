Retouch Desk · 图片文字精修

本安装程序适用于 Windows 10（1809 或更新版本）/ Windows 11 的 64 位环境。
默认安装到当前用户的应用目录，无需管理员权限；安装位置可以自行选择。

程序内置本地 CPU 处理引擎与 OCR 模型，无需安装 Python、Node.js，也不需要显卡或云端 API Key。图片不会上传。
桌面窗口使用 Microsoft Edge WebView2 Runtime；未安装该组件时，程序会尝试在默认浏览器中打开本地界面。

更新前请先导出需要保留的图片并退出旧版程序。图片和修改历史仅保留在当前会话，退出后清除。
安装完成后，可从桌面或开始菜单打开 Retouch Desk；卸载请通过 Windows“设置 → 应用”或开始菜单中的卸载入口进行。

请在采用结果前检查文字与局部放大对比。复杂背景、未知字体与手写文字仍可能需要人工调整。
