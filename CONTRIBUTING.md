# Contributing to Retouch Desk

Contributions are welcome when they become part of the official Retouch Desk project.

1. Open an issue to describe a substantial feature or change before doing extensive work.
2. Fork this repository or use another temporary working copy to prepare the change.
3. Run the relevant checks described in the README and submit a pull request to this repository.
4. Keep third-party code, fonts, and assets separately identified with their applicable license and attribution.

The project maintainer decides whether to accept a pull request. By submitting a contribution, you retain your copyright and grant the project maintainers the rights described in the repository's `LICENSE` file.

Use a GitHub fork as a workspace for proposing changes. Public GitHub repositories can be forked and used through GitHub's Service under GitHub's Terms of Service, and the project cannot disable that platform feature. The project license grants no general permission to republish this code outside GitHub or distribute a standalone app or product based on it. Keep the project's origin clear.
